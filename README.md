# 真一 ZHENYI

## 全球首个 AI 算命命理大模型

**两万多个真实命例训练 · 五百多道大赛题测试 · 83% 自测正确率 · 程序自动排盘**

真一基于 **Qwen3.8-27B** 二次训练，以盲派理法为核心，融合旺衰派、子平派和调候派的经验。项目同时提供盲派排盘程序、聊天后端和 OpenAI 兼容接口。用户发送出生资料或四柱并直接提问，后端自动排盘，再把结果交给模型分析。**排盘由程序完成，模型负责解读。**

我们开源了真一，一款以八字算命理法为核心训练、与盲派排盘系统一起交付的命理大模型。盲派给了它判断的主干，旺衰派、子平派和调候派补上各自看见的那部分。我们要做的，是让这些理法在同一张命盘上真正碰面，形成有依据的解读。

## 项目特点

- **多流派训练。** 盲派理法和技法是核心；旺衰派、子平派、调候派的师傅及相关理论也参与训练资料建设。项目团队累计使用了两万多个真实命例。
- **程序自动排盘。** 后端识别命例，调用配套排盘程序计算四柱和岁运，再把排盘摘要交给模型。模型不自行计算干支；资料不足时会提醒补充。
- **像普通模型一样调用。** 提供 `/v1/chat/completions` 和 `/v1/models`，支持多轮对话与流式响应。客户端只需发送标准聊天消息。
- **可独立部署。** 本仓库包含 TypeScript 排盘源码、网页、聊天后端及部署脚本；模型文件作为同仓库的 Release 附件提供。

## 测试记录

我们用历届全球命理师大赛的五百多道题测试真一。同一批题目、同一评分标准下，真一答对了 **83%**，人类冠军为 **40%**。这个结果连我们自己都感到震惊。我们会继续用更多命例和新的问题检验它。

*83% 与 40% 为项目团队提供的测试数据，逐题记录尚未公开。*

## 下载与部署

需要 Node.js 20+、真一合并版模型权重和支持该模型的推理环境。合并版已将真一 LoRA 写入 Qwen3.8-27B 权重，部署时只需加载一个模型目录。模型文件正在上传至本仓库的 v0.1.0 Release，核验齐全后公开。发布后下载全部附件，用 `scripts/reconstruct-model.py` 按 SHA-256 校验并还原模型。

```bash
gh release download v0.1.0 --repo ZHENYI-ORG/Zhenyi-AI --dir model-assets
python3 scripts/reconstruct-model.py model-assets model/zhenyi
npm ci
npm run build
```

模型服务和网页服务的启动命令见 [部署文档](docs/MODEL_INTEGRATION.md)。部署后，客户端可以像调用普通大模型一样提问。

```bash
curl http://localhost:8787/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"ZHENYI","messages":[{"role":"user","content":"乾造，四柱为甲子 甲戌 戊寅 庚申。请分析事业。"}]}'
```

## 为什么开源

我一直觉得，盲派、旺衰派、子平派和调候派都掌握着命理真相的一部分。难的是把这些经验放到同一个命例里检验，遇到分歧时说明判断依据。真一从盲派出发，也认真吸收其他流派的看法。

我相信，随着更多命例、反馈和不同流派的经验进入项目，真一会逐渐形成自己的解读逻辑。这套逻辑也许有一天能超出人类现有的解读范畴，达到我们今天还想象不到的高度。这是期待，仍要靠后续测试检验。

我选择开源，是希望更多师傅、研究者和开发者参与。欢迎检查排盘、讨论判断、指出错误，也提出更好的验证办法。让懂行的人一起把问题找出来，真一才能继续往前走。
