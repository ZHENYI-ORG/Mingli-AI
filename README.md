# 真一 ZHENYI｜盲派八字分析模型与排盘系统

真一（ZHENYI）是基于 **Qwen3.8-27B** 二次训练的盲派八字分析模型，配套盲派排盘系统和 OpenAI 兼容聊天接口。用户像调用普通模型一样发送命例和问题；后端识别资料、调用排盘程序，再将排盘结果交给模型解读。**四柱和岁运由程序计算，不让语言模型自行排盘。**资料不全时，系统会提醒用户补充。

本仓库提供 TypeScript 排盘源码、聊天后端、网页和部署脚本。

## 我为什么开源真一

我把真一开源了。在我们看来，它是全球首个以八字盲派算命理法为核心进行训练的命理大模型。我们把盲派的理法和技法教给它，也请旺衰派、子平派、调候派的师傅参与，纳入这些流派的理论与经验。真一基于 Qwen3.8-27B 二次训练；配套的盲派排盘系统负责计算四柱和岁运，模型专注于解读。

我们一直认为，每个流派都掌握着命理真相的一部分。真正难的，是让不同理法在同一个命例上相互印证，遇到分歧时还能讲清判断依据。为此，我们累计把两万多个真实命例用于训练。

我们又用历届全球命理师大赛的五百多道题测试了真一。按同一批题目和同一评分标准，真一的正确率达到 **83%**，人类冠军为 **40%**。我们自己也非常震惊。这组数字来自项目团队自测，题目范围和逐题评分记录尚未公开。

我相信，随着更多命例和不同流派的经验进入真一，它会逐渐形成自己的解读逻辑。这套逻辑也许有一天能超出人类现有的解读范畴，达到我们今天还想象不到的高度。这是我们的期待，也需要后续测试不断检验。

我选择开源，是希望更多师傅、研究者和开发者参与。请大家检查排盘、讨论判断、指出错误，也提出更好的验证办法。一个人积累的经验终究有限；让更多人一起把问题找出来、把方法磨扎实，真一才有机会继续往前走。

## 部署

需要 Node.js 20+、Qwen3.8-27B 底模与真一 LoRA 适配器。模型文件正在上传至本仓库的 v0.1.0 Release，核验齐全后公开。发布后下载全部附件，可用 `scripts/reconstruct-base.py` 按 SHA-256 校验并还原底模。具体启动命令和 API 示例见 [部署文档](docs/MODEL_INTEGRATION.md)。

```bash
gh release download v0.1.0 --repo ZHENYI-ORG/Zhenyi-AI --dir model-assets
python3 scripts/reconstruct-base.py model-assets model/base
mkdir -p model/adapter
unzip model-assets/zhenyi-qwen3.8-27b-adapter-only.zip -d model/adapter
```

```bash
npm ci
npm run build
npm test
```

训练原文、命例答案、私有理法提示词和私人回测记录不属于公开部署包。
