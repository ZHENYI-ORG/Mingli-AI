# 真一 ZHENYI｜盲派八字分析模型与排盘系统

真一（ZHENYI）是基于 **Qwen3.8-27B** 二次训练的盲派八字分析模型，配套盲派排盘系统和 OpenAI 兼容聊天接口。用户像调用普通模型一样发送命例和问题；后端识别资料、调用排盘程序，再将排盘结果交给模型解读。**四柱和岁运由程序计算，不让语言模型自行排盘。**资料不全时，系统会提醒用户补充。

本仓库提供 TypeScript 排盘源码、聊天后端、网页和部署脚本。项目方自测：在全国算命师大赛题目上，按本次测试的判分口径，正确率为 **73%**。该数字来自项目方测试，尚无公开的逐题结果和独立复核，仅代表本次测试。

## 部署

需要 Node.js 20+、Qwen3.8-27B 底模与真一 LoRA 适配器。模型权重暂未在本仓库公开；部署者需自行准备模型文件。具体启动命令和 API 示例见 [部署文档](docs/MODEL_INTEGRATION.md)。

```bash
npm ci
npm run build
npm test
```

训练原文、命例答案、私有理法提示词和私人回测记录不属于公开部署包。当前公开的是系统源码，模型权重暂未公开。
